# 05. 完成品・BTO購入案（自作しない場合）

> 初回調査日：2026-10-17 / 拡張日：**2026-10-22**。**2027年4月の購入候補を比較するための調査資料**であり、現時点の在庫・価格が2027年も適用される保証はない。構成の定義は [03](./03-build-plans-2027-04.md) を参照。

## 結論・比較対象

- **優先案：標準規格パーツを使うカスタマイズBTO**。特にSycom / TSUKUMO G-GEAR を構成・型番・保証・見積で比較。
- **価格対抗：FRONTIER / ドスパラ GALLERIA / パソコン工房**。セールや短納期が魅力だが、型番非公開のパーツやケース固有設計に注意。
- **大手メーカー完成品（Dell Alienware / HP OMEN 等）**も選択肢だが、筐体・電源・マザーボードの独自仕様、増設制約、保証条件を型番単位で確認。上記BTOと同じ拡張性を当然視しない。
- **完全自作**はパーツ選択・故障切り分け・アップグレード自由度で最有力。価格はBTOのセールと逆転しうる。

## 購入形態別のメリット・デメリット

| 方式 | 主な利点 | 主な弱点 | 今回の適性 |
|---|---|---|---|
| 完全自作 | 全パーツを選べる。更新・交換・切り分け自由。調達セールを活用可 | 組立・OS設定・検証・初期不良の責任を負う。故障時は部品別窓口 | ハードウェア自体を楽しむなら◎ |
| **カスタマイズBTO** | 組立・出荷検証済、完成機の保証窓口を一本化しやすい。多くの構成を変更可 | 自作ほど全パーツを選べない。サポート対象外の後付け改造がありうる | **現時点の第一候補** |
| セール型BTO | 同等CPU/GPUの安いモデルが見つかることがある。完成機ですぐ導入可 | 電源・基板・SSDの銘柄不明、容量不足・変更範囲が狭いモデルあり | 同条件見積で安ければ候補 |
| 大手メーカー完成品 | 販売・サポート窓口、製品単位の検証、購入の手軽さ | 固有筐体・独自マザーボード/PSUの可能性。GPUやクーラー交換制約 | 拡張性が実証できた機種のみ |

### BTOでも見落としやすい点

1. **同じRyzen/GeForceなら同じPCではない**：RAM規格・速度・枚数、SSD、電源、マザーボード、ケース吸排気、騒音を比較する。
2. **VRAMは後から増設できない**：小規模ローカルAIが中心なら16GBでも可。より大きいモデルや長いコンテキストを重視するならVRAM容量優先を検討。
3. **保証と改造**：自分でGPU/メモリ/SSDを換装したときの保証条件、修理時の往復送料・データ取り扱い・返却所要日数を購入前に文書確認。
4. **電源とケース**：将来32GB級ハイエンドGPUへ交換するなら、PSU容量だけでなく12V-2x6配線、クリアランス、冷却を事前確認。
5. **別立て費用**：Windowsライセンス、Wi-Fi、送料、延長保証、UPS、追加SSD、周辺機器を総額に含める。

### 3.2 LLMの複数GPU分散について

Ollama公式FAQによると、モデルが1枚のGPUのVRAMに収まる場合はそのGPUに載せる(PCIバス上のデータ移動が少なく性能面で有利になりうる)。収まらない場合は利用可能な全GPUに分割して載せる([公式FAQ](https://docs.ollama.com/faq#how-does-ollama-load-models-on-multiple-gpus))。分散の実効性能は、**ソフトの対応状況・PCIeの通信帯域・GPUの世代差(異種GPU)・メモリ使用量**に依存します。ゲーム用GPU+3070で大モデルを分割して使うことを前提にせず、GPUごとに別のモデル/タスクを割り当てる運用を基本にします。

### 3.3 物理適合のチェック項目(型番確定後)

1. 3070の**実機型番・長さ・厚み**(2〜3.5スロット)と補助電源端子(8pin本数/12pin)。
2. 新GPU(5070 Ti等)が占有するスロット数と、2枚目GPUとの**吸気間隔**。
3. ケースの対応GPU長・拡張スロット数・縦置き可否・下部ファン位置。
4. 電源のPCIe 8pinケーブル本数・12V-2x6ケーブルの有無とケーブル長。
5. 騒音・温度の許容、設置場所の排熱。
