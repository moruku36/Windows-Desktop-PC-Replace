## 2. 作業チェックリスト

### 2.1 現行機の確認(実機で。本書では未実施)

- [ ] 電源ユニットの型番・容量・世代(ケース内ラベル)
- [ ] RTX 3070の**メーカー型番・長さ・厚み・補助電源**
- [ ] モニターの解像度/リフレッシュレート
- [ ] 流用候補部品の洗い出し(流用しない前提でも可)
- [ ] 実使用電力の計測(UPS検討用)

### 2.2 バックアップと切り戻し

- [ ] 重要データを**2か所以上**にバックアップし、**復元テストを1回行う**
- [ ] 旧PCは新環境の検証が終わるまで**消去しない**・起動できる状態で保持
- [ ] 切り戻し手順: 旧PCへ作業を戻す条件(例: 新PCで重大な不具合が1週間解消しない)を事前に決める

### 2.3 秘密情報の扱い

秘密鍵・APIキー・認証トークンは**GitHubに載せない**。次は「移行」ではなく**新環境で安全に再設定/再発行**する項目として扱う。

- [ ] SSH鍵 → 新PCで新規生成し、公開鍵のみ各サービスへ登録。旧鍵は検証後に失効
- [ ] APIキー・トークン → 新環境用に再発行し、旧キーは失効
- [ ] GitHubなどへのログイン → 新PCで新たに認証(`gh auth login` 等)
- [ ] パスワード/ブラウザ同期 → パスワードマネージャー経由で再ログイン

旧環境の管理設定(レジストリ、サービス、ポリシー等)を**無差別にコピーしない**。必要な設定だけを理由を確認して再現する。

### 2.4 新PCの初期確認とセットアップ

- [ ] 外観・端子・ケーブルの欠品確認、BIOSでRAM容量・SSD認識の確認
- [ ] メモリテストとストレステスト(温度・安定性)
- [ ] OSは**クリーンインストール**。Windows Update、GPUドライバは公式から
- [ ] 開発環境(エディタ・言語処理系・コンテナ等)とAIツールを順に導入し、1つずつ動作確認
- [ ] 案Aの場合: 2GPUの認識・温度・騒音・電源の安定性を確認(ゲームとAIの同時負荷)

### 2.5 店頭・販売店への確認

- [ ] 納期(受注生産の日数)、初期不良対応期間、保証と改造時の扱い
- [ ] 3070を増設/同梱した場合の保証条件(**文書で確認**)
- [ ] 電源・基板・ケースの**型番**(BTOの場合)
