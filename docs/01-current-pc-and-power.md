## 2. 新PCの電力見積もり(2GPU構成の再計算)

### 2.2 合計と電源容量の目安

必要容量の目安 = 合計 × 1.25(**仮定**。定常負荷を約80%に収め、瞬間的な負荷変動に余裕を持たせる)。ただし単GPUの推奨電源を下回らない。

| 構成 | 合計(最大負荷の積み上げ) | ×1.25 | 推奨する電源クラス |
|---|---|---|---|
| 小・単GPU(5070 Ti) | 162+300+100 = 562W | 約703W | 850W(NVIDIA推奨750W以上) |
| 小・案A(5070 Ti+3070) | 162+300+220+100 = 782W | 約978W | **1000W** |
| 中・単GPU(5080) | 162+360+100 = 622W | 約778W | 850W |
| 中・案A(5080+3070) | 162+360+220+100 = 842W | 約1053W | **1000〜1200W** |
| 大・単GPU(5090) | 230+575+100 = 905W | 約1131W | 1200W |
| 大・案A(5090+3070) | 230+575+220+100 = 1125W | 約1406W | **1500W級が必要。家庭の15A回路では他機器との合算に余裕がなく非推奨** |

- 2GPU同時に最大負荷になる使い方は稀ですが、**ゲーム中にもう一方のGPUで推論を回す**と近づきます。
- 家庭側: 100V/15A回路の上限は1500W。壁側の消費はDC側÷電源効率(約0.9と仮定)で、例えば小・案Aは約870W。**同じ回路のモニター・エアコン・UPS等との合算**を確認してください(未確認)。
- 電源は容量だけでなく、ATX 3.1/PCIe 5.1対応、品質(第三者の負荷試験・保護機能)、保証年数を比較します。安価な電源(参考: 850W級が約1.1〜1.3万円、1000W級が約1.3〜1.6万円の表示あり)は品質未確認のため、本書の総額では**品質電源として約3万円を仮置き**しています。

### 2.3 コネクタとケーブル本数

- 5070 Ti: 8pin×2のアダプタ同梱、または300W以上の12V-2x6(PCIe Gen5)ケーブル。5080: 8pin×3、または450W以上の12V-2x6。5090: 8pin×4、または600W以上の12V-2x6。
- RTX 3070: FE相当は8pin×1(12pin変換)。**AIBモデルは型番未確認**で、8pin×1〜2や12pinなどが混在します。
- 案Aでは「新GPU用の12V-2x6ネイティブ×1」+「3070用の独立したPCIe 8pin系統」が確保できる電源が望ましい。アダプタ多用は配線とケース内スペースの面で不利です。
- 12V-2x6は曲げ半径に注意(コネクタ直近で急に曲げない)。必要な余裕はケース幅とGPU寸法で変わるため、実機の寸法で確認します。

## 3. UPS(任意)

UPSは別途費用。容量は実測の消費電力・力率・瞬間負荷・シャットダウン要件で決めます(現時点で計測値なし)。この文書では推奨しません。
