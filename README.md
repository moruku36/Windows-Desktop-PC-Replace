# Windows Desktop PC Replace(2027年4月までの買い替え計画)

**目的**: 遅くとも **2027年4月末** までに Windows デスクトップを買い替える。用途は GTA VI(PC版が出た場合)と、AIエージェント/ローカルLLM。**この計画は調査・文書のみで、購入・予約・PC設定変更は行っていません。**

> 調査日: **2026-10-22**。価格は税込の**参考価格**(kakaku.com 最安表示。販売店・在庫は未確認)と、FRONTIER等の店舗掲載価格を区別して記載しています。2027年の価格は予測していません。

## 結論

### 現時点の推奨案

- **小(Ryzen 7 9800X3D + RTX 5070 Ti 16GB + DDR5 64GB)を基本にし、RTX 3070は旧PCに残してAI用に使う(案B)**。総額の目安は **約58万円**(RAM 32GBなら約52万円)。
- 期限を守る保険として、**段階購入(新基盤 + 3070で先行、GPUは後日)** を用意(約37万円)。
- 2GPU同居(案A)は、3070の型番・ケース・電源を確認してから。

### 避けたい構成

- **RTX 5090 + 3070同居**: 参考価格で約158万円、電源1500W級となり家庭の15A回路でも余裕がない。
- 未発表品(RTX 50 SUPER 24GB、Zen 6)を前提にした購入計画。
- 品質未確認の安価電源での2GPU運用、型番未確認の3070を前提にしたケース選び。
- 高価な x8/x8 基板(参考価格差 約5.7万円)を「必須」と決め打ちすること。

### 公式発表後に再判断する部分

- **GTA VI のPC版**: Rockstar公式は **2026年11月19日 PS5 / Xbox Series X|S** のみ。**PC発売日・PC要件は未確認(未発表)**([公式](https://www.rockstargames.com/VI)、確認日 2026-10-22)。
- GPUクラス、CPU(8コア/16コア)、RAM容量(32/64/128GB)は、公式要件と用途の測定後に確定。
- 「2027年Q1のPC版」「RTX 50 SUPER 24GB」「Zen 6」は報道・噂で、**公式未確認**。「AM5は2029年まで」は報道あり・AMD一次資料は未確認。
- 最終見積は **2027年2〜3月** に取り直す。

### 本人に確認する最小項目

1. 予算の上限(旧枠は現在の価格に合わない)
2. モニターの解像度・リフレッシュレート
3. RTX 3070 のメーカー型番(長さ・厚み・補助電源)
4. 現行の電源ユニット型番(流用しない前提でも、2GPU可否と電源仕様の確認に使う)
5. ローカルAIで使いたいモデル・量子化・コンテキスト長・同時実行数(未定なら「クラウドAPI中心」と仮定)
